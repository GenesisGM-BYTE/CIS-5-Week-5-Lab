# Running this project on Replit

This is a C++ console assignment with one source file and no external dependencies or secrets. The C++ compiler (`g++`) is already available.

Use the **Run** button (the "Run C++ assignment" console workflow), or run this command in the Shell:

```bash
g++ -std=c++17 -o program main.cpp && ./program
```

The program is currently an assignment starter with TODOs. It compiles and exits without prompting until those TODOs are completed. After implementing the prompts, enter an age and a GPA in the console when asked.
